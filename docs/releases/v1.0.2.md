**Swims count by distance in each week, in metres or yards.**

## Calendar

- **Swim volume by distance.** Swims are usually planned by distance with no
  time (a CSS set is 10 × 100 m, not 38 minutes), so the Swim line beside
  each week read "0m / 0m". It now shows the distance you swam against the
  distance planned, in metres or yards to match your units setting, with the
  time you swam beside it.
- **A swim planned by time alone** keeps its time on that line: a week with a
  1,800 m set and an easy 45-minute swim reads "1,800 m + 45 min".
